⚠️
GLM-5.2 is 753B MoE — BF16 weights alone are ~1.5 TB; FP8 is ~753 GB (needs 10+ H100s). The plan below uses AWQ INT4 quantization (~376 GB) which fits on a single 8×H100 80 GB node (640 GB pool, TP=8). This is practical for a POC demo; upgrade to FP8 on 2 H100 nodes (~$20K extra/month) for production-quality inference. Gemma 4 31B and Qwen3.6-35B-A3B run in BF16 on a separate A100 node.
